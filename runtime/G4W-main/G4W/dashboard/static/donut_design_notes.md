## 决定性几何事实(标签能放下的条件)
- 标签盒宽≈43(休息)/37.5(工作/学习),锚点在 R=outer+8 处
- 左侧空间 = 100 - (outer+8)*|cos(mid)| - w:休息 mid=-160.6° 时需 100-0.944*(outer+8)-42.8 > 2 → outer ≤ 48
- 右侧空间:工作 x1=100+(outer+8)*cos(22.6°)+37.5 ≤ 198 → outer ≤ 52;学习同理
- 压环:学习标签(3.1°)box 内侧点距圆心 = hypot(48.5, (outer+8)*0.054+5.5) 需 > outer-1 → outer ≥ ~48 附近临界
- **结论:真实3类数据纯径向最优 outer≈48(视觉133px/277=48%,接近参考站50%)**
- 扫描下限必须 ≤44,否则纯径向永远失败 → 误走 freeMove 长引线(95.7)

## 实现要点(已落盘 app.js renderDonut)
1. 起点 0°(3点钟)逆时针累积(参考站方向):angle -= sweep
2. donutSegmentPath 支持方向:sweep flag = span>0?1:0,large = |span|>180
3. 方案A pureRadial:标签零微移、固定 R=outer+8、anchor 按 cos 符号;检查重叠/压环/越界(2..198),outer 从 88 递减到 44
4. 方案B freeMove:120 迭代分离重叠 + 环外推 + 边界钳制;同范围扫描
5. 优先级:先全扫 A,失败才 B(避免 B 在 84 提前通过产生长引线)
6. 兜底 raw:全部失败时 outer=88 原样渲染
